# Cybersecurity Workshop Website

This is a ready-to-use static website for the 2-Day Cybersecurity Workshop by BinnBash Academy.

## Structure
- index.html → Main site
- styles.css → Styles
- script.js → Countdown & WhatsApp
- assets/ → Images (logo, social share, favicon)
- favicon.png → Site icon

## How to Use
1. Open `index.html` in a browser to preview.
2. Update workshop date in `script.js` (eventDate).
3. Replace logo in `assets/logo.svg`.
4. Deploy to Netlify/Vercel/GitHub Pages.
